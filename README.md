### 🚀 Sobre Mim
Sou um **Desenvolvedor Fullstack** focado em construir aplicações escaláveis e seguras. Tenho experiência sólida em arquiteturas de backend (Java/Python) e interfaces modernas (React/Angular), além de vivência com deploy em nuvem e automação de processos.

- 🛠 **Backend:** Especialista em ecossistemas Java (Spring Boot) e Python (Django, FastAPI).
- 🔐 **Segurança:** Implementação de padrões como JWT, RBAC, CSRF e integração com serviços de diretório (LDAP).
- ☁️ **Cloud:** Experiência com Google Cloud Platform (GCP) e containerização com Docker.
- ⚙️ **Integrações:** Domínio de APIs de pagamento (Asaas) e comunicação (SendGrid, Brevo).
